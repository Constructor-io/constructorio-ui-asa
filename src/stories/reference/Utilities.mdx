# Utilities

## `normalizeItemToProduct(item, options?)`

The default mapping from a raw search result to the `Product` a card renders. Extend it in your own `normalizeItem`. See [Product Results](?path=/docs/guides-product-results--variants#mapping-product-data).

## `clearPersistedConversations({ apiKey, domain?, userId? })`

Deletes stored conversations in every tab, for example on logout. Resolves once recorded. `domain` defaults to `'chatbot'`; without `userId` it clears the current tab's guest history. See [Conversations](?path=/docs/guides-conversations--variants#login-and-logout).

## `renderMarkdown(markdown)`

Turns the agent's markdown (bold, links, lists, tables) into sanitized HTML, the same way `Chat` renders replies. Scripts, images and inline styles are removed, and links to other sites become plain text: only links to the current site, its subdomains stay clickable. For a custom UI that shows `message` events itself. Browser only: on the server it returns `''`, so render the plain text. Style the HTML yourself, or see `AiMessage.css` for the classes `Chat` uses.

```jsx
<div dangerouslySetInnerHTML={{ __html: renderMarkdown(message.text) }} />
```
